<h1>SoundSensor - Winter term project </h1> 
<hr>

A project aimed to develop a sound sensor to be placed around Western University's campus for prolonged periods of time in order to measure sound as readable data
to map the soundscape in order to aid with research.

<p> 
  <h3>Physical Components: </h3>
  <ul>
    <li>ESP-32 WROOM</li>
    <li>ICS-43434 Microphone </li>
    <li>MircoSD Module (FAT32)</li>
    <li>DS1203 Real-TimeClock </li>
  </ul>
</p>

<p>
  <h3>Languages/Tools:</h3>
  <ul>
    <li>C++ </li>
    <li>Arduino Framework </li>
    <li>PlatformIO</li>
    <li>VsCode</li>
  </ul>
</p>
